# S.A Education — Front-end

Estrutura baseada no protótipo enviado, com áreas separadas para:
- Login e cadastro
- Cadastro institucional para escolas, faculdades e universidades públicas ou particulares
- Início
- Salas de estudo
- Detalhes da sala
- Criar sala
- Entrar em uma sala
- Quiz
- Ranking
- Perfil
- Menu lateral

Tecnologias: HTML5, CSS3, JavaScript e PHP.
O projeto usa dados demonstrativos em PHP para a interface; não há banco de dados nesta versão.
Para testar as páginas PHP, use XAMPP/WAMP/Laragon ou o servidor embutido do PHP.
